Security model

Umbrel-authenticated web UI. Only Stratum is published to the LAN. No Docker socket, no privileged container, no wallet secret fields, capped Docker logs, persistent backend state, and no second password system.

Important: this initial implementation uses c2pool embedded LTC/DOGE SPV mining backends to keep installation simple. Full pruned Litecoin/Dogecoin Core mode is a planned refinement after physical mining acceptance.
